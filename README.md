# Customer Shopping Behaviour Analysis (Python → SQL → Power BI)
End-to-End Data Analytics Project (Python | SQL | Power BI)
📌 Project Overview

This project focuses on analyzing customer shopping behavior to uncover patterns in purchasing, revenue generation, and customer segmentation.

Using a combination of Python, SQL, and Power BI, the project delivers actionable insights that support data-driven decision-making, similar to how analytics is used in real-world business environments.

🎯 Business Objective

Retail businesses often struggle to understand:

Which customers contribute most to revenue
Which product categories perform best
How demographics influence purchasing behavior
Whether marketing strategies (discounts, subscriptions) are effective

This project aims to answer these questions through structured data analysis and visualization.

📊 Dataset Description

The dataset contains customer transaction data including:

Customer demographics (Age, Gender, Location)
Product details (Category, Item, Size, Color)
Purchase behavior (Amount, Frequency, Season)
Customer engagement (Subscription, Discounts, Promo codes)
Ratings and reviews
Shipping preferences
⚙️ Project Workflow
1️⃣ Data Preprocessing (Python)
Data cleaning and transformation
Handling missing values
Feature engineering (Age groups, purchase patterns)
Exploratory Data Analysis (EDA)
2️⃣ Data Analysis (SQL)
Revenue analysis by category and gender
Customer segmentation queries
High-value customer identification
Product performance analysis
Purchase behavior trends
3️⃣ Data Visualization (Power BI)

An interactive dashboard was created to visualize insights.

Key dashboard features:
Customer segmentation
Revenue by category
Sales distribution
Age group analysis
Subscription impact
KPI metrics (Total Customers, Avg Purchase, Ratings)
📈 Key Insights
Customers using premium shipping options spend more on average
Certain product categories drive higher revenue and sales volume
Subscription-based customers show higher engagement
Age groups influence purchasing patterns significantly
Discounts impact buying behavior but must be optimized
💡 Business Recommendations
Promote subscription-based engagement programs
Focus marketing on high-value customer segments
Optimize discount strategies for profitability
Prioritize high-performing product categories
Improve targeting using demographic insights
